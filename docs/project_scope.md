
# Anomera — Project Scope

## Problem Statement

Credit card fraud is a rare but costly event.
The goal is to identify suspicious transactions while
controlling the number of false alerts.

## Objectives

- Detect potentially fraudulent transactions.
- Evaluate models under severe class imbalance.
- Prioritize transactions for investigation.
- Build a reproducible machine learning pipeline.

## Dataset

ULB Credit Card Fraud Detection dataset.

## Current Phase

Phase 1 — Data Foundation.
